## Implemented

- Tauri 2 + React + TypeScript main window with Dashboard, Workspaces, Routing, Clients, Migration, Logs and Settings. State comes from the owned backend over private pipes; no frontend mock or unauthenticated management port. Not-yet-implemented actions are visibly disabled.
- Shared Node `Service` and SQLite WAL registry for GUI, developer CLI and MCP v2. Four read-only MCP tools: workspace list/verification, exact-workspace search and page retrieval. Official Notion adapter explicitly pins API `2026-03-11`.
- Per-workspace Windows Credential Manager reads, a hidden developer enrollment prompt, identity checks before every content request, fixed safe error mapping, and backend activity events. No tokens in frontend state, SQLite, command arguments or source fixtures. Test UUIDs are generated at runtime.
- Pinned, SHA-256 checked Node `v26.13.1` Windows x64 runtime, bundled backend, credential bridge and license notices. The installer runs without locating Node on PATH.
- Reused `assets/LV999.ico`; distinct app/data identity `com.rampageboo.lv999`. Custom pinned upstream NSIS template also isolates install/uninstall registry entries, default program path, shortcuts and autostart cleanup from legacy LV999. Uninstall preserves user data and disables legacy WiX discovery.
- GitHub Actions CI and draft prerelease workflow using `tauri-action`, a new LV999 updater public key and this repository's `latest.json`. No tag, release, GitHub secret upload, client configuration change or deployment was performed. Local signing key is ignored under `.tools`; secure backup and Actions secret provisioning remain release preparation.
